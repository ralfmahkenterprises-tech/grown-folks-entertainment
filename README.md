# Grown Folks Entertainment

A multi-page static website for classic R&B, slow jams, soulful grooves, and grown-up nights.

## Pages

- Home (`index.html`)
- Moods (`moods.html`)
- The Standard (`standard.html`)
- Our Story (`story.html`)

The site uses plain HTML, CSS, and JavaScript and can be hosted with GitHub Pages or uploaded directly to cPanel.

## Custom domain

After choosing a domain in the GitHub Pages settings, add the domain to a `CNAME` file at the repository root and configure the DNS records GitHub provides.
